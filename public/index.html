🛠️ Configuration du Bot Discord

Configuration requise

Entrez votre jeton de bot et l'identifiant du salon ci-dessous.

Bot en ligne : Non
Salon surveillé : -
Clé Config : Incomplète
1
Créer l'application Discord

Rendez-vous sur le Discord Developer Portal et cliquez sur New Application.

2
Créer le Bot & Activer les Intents

Allez dans l'onglet Bot. Activez le paramètre Message Content Intent (Crucial pour lire les messages !) puis copiez le Token du bot.

3
Inviter le bot sur votre serveur

Allez dans OAuth2 > URL Generator. Cochez bot. Dans les permissions du bot, cochez Read Messages/View Channels. Utilisez le lien généré pour inviter le bot.

4
Copier l'ID du Salon

Sur Discord, activez le mode développeur (Paramètres > Avancés). Faites un clic droit sur le salon textuel choisi et cliquez sur Copier l'identifiant.

Remplissez ces informations. Elles seront enregistrées en mémoire pour cette session.
